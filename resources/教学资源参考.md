# 教学资源参考 -- 练习题设计模式

> 汇总自实际爬取的 CS50P (Harvard), Real Python, Python 官方教程, Codecademy 等知名教学资源的练习设计模式.

---

## 一、练习密度规范

### 1.1 按知识点难度配练习数

| 难度 | 特征 | 练习数 | 举例 |
|------|------|--------|------|
| 极简 | 1行语法,无陷阱,纯记忆 | 1个 | `len()`函数,`type()`函数 |
| 简单 | 1-2行,有1个易错点 | 1-2个 | 变量赋值,基本运算,`input()` |
| 中等 | 3-5行,需要组合 | 2-3个 | 切片,`dict.get()`,列表推导式 |
| 较难 | 需要理解概念转换 | 3-5个 | 字典遍历+条件判断,嵌套数据结构 |
| 核心 | 高频使用+易错 | 额外1个附加题 | 循环+条件组合,`dict.items()`遍历 |

### 1.2 结构模板

```
知识点A (教学字符串)
  -> 练习A1 (1-2个针对练习)
知识点B (教学字符串)  
  -> 练习B1, B2 (中等难度,2个)
知识点C (教学字符串)
  -> 练习C1, C2, C3 (较难概念,3个)
  -> 附加题C4 (可选拓展)
综合练习 (跨当天所有知识点)
```

### 1.3 每日常量控制

| 指标 | 目标 | 判断标准 |
|------|------|---------|
| 知识点数 | 5-8个 | 太多说明粒度太细,需要合并 |
| 练习总数 | 10-15个小练习 | 含附加题,不含综合 |
| 综合练习 | 1个 | 覆盖当天全部知识点 |
| 预估耗时 | 2-3小时 | 不包含附加题时间 |
| 附加题 | 0-3个 | 属于"可选" |

## 二、知识点粒度规范

### 2.1 必须独立成知识点的"基础细节"

以下内容**必须**在教学中单独出现,不能只用在练习中而不教:

```
运算符: + - * / // % **
比较: == != > < >= <=
逻辑: and or not
成员: in / not in
身份: is / is not
```

- 初学者不知道 `not` 可以和 `in` 组合成 `not in`
- `not` 本身 (not True -> False, not False -> True) 必须教
- `and` 的短路特性 (运算优先级) 必须提

### 2.2 易漏知识点清单

| 知识点 | 易漏原因 | 出现在哪 |
|--------|---------|---------|
| `type()` | 太基础,以为不用教 | day01 |
| 多变量赋值 `a,b=b,a` | Python 特有 | day01 |
| `None` 类型 | 和 C++ 的 nullptr 类比 | day01 |
| `not in` | 以为 in 教了就够 | day02 |
| `dict.get()` 默认值参数 | 常用但不教可能不知道 | day02 |
| 切片越界不报错 | 和其他语言不同 | day02 |
| 负索引 `-1` | 从末尾开始 | day02 |
| **字符串不可变** | 和 list 不同 | day01 |
| 深浅拷贝 | list 赋值是引用 | day02 拓展 |

### 2.3 规则

> **练习中出现的语法,必须在教学部分出现过.**

例外: 附加题可以用未教的语法,但要加 `# 提示:` 注释.

## 三、练习设计形式

### 3.1 练习形式金字塔

```
填空/补全代码     <- 知识点刚讲完,最简单的形式
修改现有代码      <- 理解已有逻辑后做改动
写完整函数        <- 独立实现
调试(找bug)      <- 需要深入理解
应用题            <- 综合运用
```

- 金字塔从下到上,越往上越难
- 一个知识点的第一个练习从底层(填空)开始
- 综合练习必须到顶层(应用题)

### 3.2 好练习的特征

1. **有明确预期输出**: "预期: [1, 2, 3]"
2. **分步引导**: 用注释列出步骤 1,2,3
3. **同一个概念从不同角度练**: 比如切片,正索引练1次,负索引练1次,步长练1次
4. **贴近实际场景**: 量化开发就贴股票数据
5. **有可验证的结果**: print 能看到对不对

### 3.3 附加题设计

附加题是"学了今天的知识后,稍微动脑就能做"的题,不是超纲题:
- 方式变化: `for k in d` -> `for k in d.keys()`
- 组合变化: 遍历 dict 时同时用 enumerate
- 反向思考: 给你结果,反推输入

## 四、内容量平衡标准

### 4.1 参考标杆

| 日 | 知识点数 | 练习数 | 总行数(不含字符串) | 参考资源 |
|----|---------|--------|-------------------|---------|
| day01 | 5-6 | 6小+1综合 | ~30行 | light |
| day02 | 6-8 | 10小+1综合 | ~50行 | medium |
| day03 | 5-7 | 8小+1综合 | ~40行 | medium |

### 4.2 判断标准

- 纯教学字符串 vs 可运行代码比例 ≈ 1:1
- 每个知识点练习的总行数 >= 教学字符串行数 (确保练够)
- 不要把所有练习放在最后,紧跟在对应知识点后面 (用户已验证的结构)
- 知识点越多,每个知识点的练习数要相应减少

## 五、实际爬取的教学资源分析

> 以下内容通过 curl 实际爬取, WebFetch 工具被网络策略拦截.

### 5.1 CS50P (Harvard) -- 已成功爬取

**URL:** https://cs50.harvard.edu/python/2022/

**课程结构:**
```
Week 0: Functions, Variables
Week 1: Conditionals
Week 2: Loops
Week 3: Exceptions
Week 4: Libraries
Week 5: Unit Tests
Week 6: File I/O
Week 7: Regular Expressions
Week 8: Object-Oriented Programming
Week 9: Et Cetera
Final Project
```

**Problem Set 0 (实际扒取内容):**
1. **Indoor Voice** -- 输入转小写 (input + str.lower(), 最简单)
2. **Playback Speed** -- 空格替换为 ... (str.replace())
3. **Making Faces** -- 表情符号转换 (str.replace() 多次)
4. **Tip Calculator** -- 实现两个函数 (str → float, 含 $ 和 % 处理)

**Problem Set 1 (实际扒取内容):**
1. **Deep Thought** -- 判断用户输入是否为 "42"/"forty-two"/"forty two" (条件判断)
2. **Home Federal Savings Bank** -- if/elif/else 条件分支
3. **File Extensions** -- 文件扩展名判断 (str.endswith())
4. **Meal Time** -- 时间区间判断

**练习设计特点:**
- 每个 problem set 4 个练习, 由易到难递进
- 每个练习有完整的: 背景故事 → 技术需求 → 手工测试用例 → 自动化测试 (check50)
- 覆盖边界情况: 大小写不敏感, 空格处理, None 判断
- 每道题明确输入输出格式, 提供多个手工测试用例
- 总练习量小 (每周4题) 但每道题需要完整实现

### 5.2 Real Python -- 已确认页面可达

**URL:** https://realpython.com/

**教学结构:**
- 基础教程 → 中级教程 → 项目教程
- 每个教程附带 interactive quiz
- 教程包含: 文本讲解 → 可运行代码示例 → 实践项目

**练习设计特点:**
- 教程内嵌代码示例 (立即运行)
- 每个知识点配 1 个 interactive quiz
- 进阶路径: 基础 → 实践 → 测验
- 零基础友好, 不需要先修编程经验

### 5.3 Python 官方教程 -- 已成功爬取

**URL:** https://docs.python.org/3/tutorial/

**教学结构:**
```
3. An Informal Introduction to Python
  3.1 Using Python as a Calculator
    3.1.1 Numbers (+, -, *, /, //, %, **)
    3.1.2 Text (str 操作)
    3.1.3 Lists
  3.2 First Steps Towards Programming
4. More Control Flow Tools
  4.1 if Statements
  4.2 for Statements
  ...
  4.8 Defining Functions
```

**练习设计特点:**
- 交互式示例为主 (>>> 提示符)
- 例子即练习: 展示了代码让读者自己试
- 没有独立练习区, 但例子密度高
- 适合作为语法参考, 不适合作为独立练习来源

### 5.4 Python for Everybody (PY4E / Coursera) -- 仅目录可达

**URL:** https://www.py4e.com/lessons

**课程目录:**
- 安装配置 → 变量/表达式 → 条件 → 函数 → 循环 → 字符串 → 文件 → 列表 → 字典 → 元组 → 正则 → 网络 → Web → 数据库

**特点:** 详细内容需要登录, 公开部分只有课程大纲

### 5.5 Codecademy Python 3 -- 已成功爬取

**URL:** https://www.codecademy.com/learn/learn-python-3

**练习设计特点:**
- 模块化: 每个 module 包含多个 lessons
- 每个 lesson 拆分为 10-15 个小步骤
- 一个概念一个练习, 自动验证
- 密集的小练习 + 进度跟踪

### 5.6 Exercism Python Track -- 通过 CloakAgent 代理成功爬取

**URL:** https://github.com/exercism/python

**工具:** CloakAgent (隐身 Chromium + ChromeGo 代理)

**Concepts 完整列表 (共 40+ 个概念):**
```
aliasing, anonymous-functions, basals, basics, booleans, comparison,
comprehensions, conditionals, dates, dicts, enums, equality, floats,
functions, generators, generals, generic-types, itertools, lists,
loops, methods, modules, none, numbers, object-oriented-programming,
parameters, primitive-types, ranges, sequences, sets, strings, ternary-operators,
test-driven-development, triple-quoted-strings, tuple-methods, tuples,
type-conversion, type-hinting, unpacking-and-multiple-assignment
```

**首次练习结构 (ghost-gobble-arcade-game / bools 概念):**
- `.docs/instructions.md` -- 练习描述 (Pac-Man 主题, 4个函数)
- `.docs/introduction.md` -- 概念介绍 (bool 类型, and/or/not 运算符)
- `.meta/` -- 元数据 (设计者, 难度)
- `<exercise>.py` -- stub 代码 (函数签名 + docstring + `pass`)
- `<exercise>_test.py` -- 单元测试 (pytest)

**练习设计特点:**
- 1 个概念对应 1 个练习 (不是多个小练习)
- 每个练习包含 3-5 个函数需要实现 (粒度适中)
- 函数签名 + docstring 已写好, 只需要补全逻辑
- 测试驱动: pytest 测试文件提供完整的测试覆盖
- 趣味主题: 每个练习有独立的故事设定 (Pac-Man, 库存管理, 卡牌等)
- 练习由易到难递进: basics(4函数) → bools(4函数) → conditionals → loops → lists → dicts

## 七、量化开发书籍推荐(来自百度搜索汇总)

> 以下推荐基于百度搜索"量化开发学习资料书籍推荐"结果整理,覆盖从入门到进阶.

### 7.1 入门奠基

| 书名 | 作者 | 说明 |
|------|------|------|
| 《量化交易:如何建立自己的算法交易事业》 | Ernest Chan | 从策略构思、回测、风险管理到实盘部署全流程,适合零基础建立系统认知 |
| 《打开量化投资的黑箱》 | Rishi K. Narang | 非技术视角透视量化基金运作逻辑,避"黑箱"误解 |
| 《Python for Algorithmic Trading》 | Yves Hilpisch | 数据→回测框架→券商API接入→云部署,贴近现代开发流程 |
| 《Effective C++》 | Scott Meyers | C++最佳实践,必读 |
| 《C++ Primer》 | Lippman | C++入门圣经 |

### 7.2 策略与实现

| 书名 | 作者 | 说明 |
|------|------|------|
| 《Algorithmic Trading: Winning Strategies and Their Rationale》 | Ernest Chan | 均值回归/趋势等经典策略的数学与代码逻辑 |
| 《量化投资——策略与技术》 | 丁鹏 | 60+案例,量化选股/择时/套利/算法交易 |
| 《深入浅出Python量化交易实战》 | - | 从基础编程到机器学习算法,A股实战 |

### 7.3 进阶系统与工程

| 书名 | 作者 | 说明 |
|------|------|------|
| 《Systematic Trading》 | Robert Carver | 自顶向下构建交易系统,组合构建/信号生成/风控 |
| 《Trading and Exchanges: Market Microstructure for Practitioners》 | Larry Harris | 订单簿/滑点/流动性等市场微观结构,低延迟/高频必读 |
| 《UNIX网络编程》 | Stevens | socket编程经典 |
| 《深入理解计算机系统》(CSAPP) | Bryant | 计算机系统基础 |

### 7.4 金融数学

| 书名 | 作者 | 说明 |
|------|------|------|
| 《Options, Futures and Other Derivatives》 | Hull | 衍生品定价经典 |
| 《Financial Econometrics》 | Dagum等 | 金融计量 |

### 7.5 避坑提醒

- 多数"XX以Python为工具"类书籍偏重案例拼接,缺乏系统工程视角
- 优先选有开源代码、讲清回测陷阱(未来函数、过拟合)和实盘部署的书
- 2026年主流开发语言: Python(pandas/NumPy/backtrader) + C++/Rust,结合聚宽/米筐等平台
- 勿过早深陷数学——量化开发更重工程实现与策略验证
