## 一、路线结论

### 1.1 主目标

**量化交易系统 / 策略系统开发工程师**

核心能力链:

```
Python数据闭环
  -> 现代C++ + 数据结构算法
  -> Linux / 测试 / 调试 / 性能
  -> 并发 / 网络 / SQL / 市场微观结构
  -> 回测引擎
  -> 交易链路模拟器
  -> 实习与定向补强
```

### 1.2 现实入口

| 路线 | 定位 | 与主线重叠 | 额外补充 |
|------|------|------------|----------|
| 交易系统/低延迟 | 主攻 | 最高 | 体系结构、性能、网络、并发 |
| 策略系统/研究平台 | 主攻 | 最高 | 回测、数据、并行、量化业务 |
| 量化数据/研究基础设施 | 第二入口 | 高 | SQL、数据质量、平台工程 |
| C++系统/FinTech后端 | 保底 | 高 | 服务端工程、数据库、分布式 |
| AI基础设施/AI应用 | 定向分支 | 中 | PyTorch/GPU或RAG/Agent，不能替代系统底座 |

### 1.3 关键判断

- 本科可以投量化开发，但必须用工程能力、项目、竞赛或实习抵消筛选劣势。
- 金融背景不是多数工程岗的前置，计算机基础和编程质量更关键。
- Python是必要入口；C++、Linux、算法、系统工程决定差异化。
- AI不再固定占25%-40%。主线达标后，最多使用阶段时间的15%做一个可验证辅线项目。
- 不再追求“项目数量”和“刷题总数”本身，改看质量、复现、间隔重做和面试稳定性。

## 三、毕业能力目标

### 3.1 编程与系统

- Python: 能写可靠的数据管道、分析模块和测试。
- C++: 熟练 C++17/20、STL、RAII、移动语义、并发和工程构建。
- Linux: 能使用 Shell、进程/文件/网络工具，能调试和定位性能问题。
- 算法: 常见结构和模式能在限定时间内独立完成，并解释复杂度和边界。
- 工程: Git、CMake、pytest/gtest、sanitizer、CI、日志、benchmark。

### 3.2 量化业务

- 理解行情、信号、订单、风控、成交、持仓、资金和监控的端到端链路。
- 能解释回测中的未来函数、幸存者偏差、交易成本和过拟合。
- 能用数据质量和可复现性约束研究流程。

### 3.3 证明材料

目标不是“5个以上项目”，而是:

1. Python 股票数据与分析工具
2. C++ 市场数据回放/性能项目
3. C++ 回测引擎
4. C++ 交易链路模拟器

其中最终简历重点保留2-3个最强项目。每个核心项目必须有:

- 可运行说明
- 自动测试
- 样例数据与结果
- 架构图或模块说明
- 性能或可靠性证据
- 一次故障/错误复盘

### 3.4 面试训练

- 阶段2: 80-120道独立题 + 30-50次间隔重做。
- 阶段4: 累计150-200道独立题，重点覆盖高频模式和限时稳定性。
- 秋招前: 200-250道高质量独立题 + 系统化错题复刷。

题数只是工作量指标，最终验收是限时解决、复杂度说明、边界测试和复盘。

## 五、阶段规划

### 阶段1: Python数据闭环

**定位:** 学到足够支撑数据处理、回测入门和第一个项目，然后进入C++。

**保留:**

- Python核心语法、模块、文件与异常
- NumPy、Pandas、Matplotlib
- Git、类型注解、pytest基础
- 单一可靠数据源、清洗、数据质量
- 本地Pandas回测基础

**删除或后移:**

- collections/itertools/generator集中灌输
- 多数据源降级系统
- Web UI、数据库、复杂Agent
- 阶段1就做完整交易系统

**验收:** `stock-analysis-tool` 可运行、有README、有最小测试，能从原始行情得到清洗表、指标和图。

详细计划: `docs/plans/阶段1_Python_分脉络大纲.md`

### 阶段2: 现代C++与数据结构算法

**顺序:**

1. 编译器、CMake、Git、Linux开发环境
2. 类型、函数、引用、生命周期、string/vector
3. 类、RAII、错误处理、测试与sanitizer
4. STL、复杂度、数据结构和算法
5. 交易语境小模块

**原则:**

- 不把 `new/delete` 当默认资源管理方式。
- 每周有一个可运行模块和一次复盘。
- 每题包含复杂度、边界和最小测试。

详细计划: `docs/plans/阶段2_C++算法_分脉络大纲.md`

### 阶段3: C++系统与性能

四周只做一条集成主线:

- RAII、拷贝/移动、智能指针
- 内存布局、缓存、容器选择
- 并发与线程安全
- benchmark、sanitizer、调试和性能分析
- 市场数据回放/处理项目

内存池、STL源码和高级模板作为选做，不与主项目抢时间。

详细计划: `docs/plans/阶段3_C++深入_分脉络大纲.md`

### 阶段4: 量化系统核心

**时间下限:** 量化系统主线至少85%；AI工具化最多15%，且必须先过主线门槛。

**主线:**

- Linux系统工具与性能排障
- C++并发、网络、协议和状态机
- SQL、数据质量和可追溯性
- 市场微观结构、订单簿、撮合、交易成本
- C++事件驱动回测引擎
- C++交易链路模拟器

**AI门槛:**

只有当当期主线任务、算法复习和项目测试都通过，才二选一:

1. PyTorch量化因子小实验
2. 回测运行/报告解释工具

不同时做RAG、Agent、微调和部署。

详细计划: `docs/plans/阶段4_量化核心AI_分脉络大纲.md`

### 阶段5: 第一段真实经历

优先级:

1. 量化开发、交易系统、研究平台实习
2. 券商IT、FinTech、C++系统或数据平台实习
3. 实验室、开源协作、老师项目
4. 自主项目冲刺

没有拿到实习时不空转，走等价替代分支并保留下一轮投递机会。

### 阶段6: 定向冲刺

- 深挖已有项目，不再无边界新增技术栈。
- 根据实际JD选择低延迟、数据平台、分布式或AI基础设施中的一个分支。
- 量化与C++系统/FinTech双线投递。
- 考研复习按 `docs/plans/考研备考对照表.md` 单独管理。

详细计划: `docs/plans/阶段5-6_实习与冲刺_分脉络大纲.md`
