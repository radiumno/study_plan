## 三,2026年行业趋势(二次调研发现)

### 3.1 市场热度:高位运行但结构性分化

- 头部百亿私募（乾象、天演、明汯）持续扩招，AI+量化岗位数量同比增长显著
- 竞争已进入地狱模式：某头部量化基金 30 个实习岗收到 15000 份简历（录取率 0.2%）
- 纯传统量化岗增速放缓，增量集中在 AI/ML 复合方向
- **表面看起来机会多，实际上更难进了**

### 3.2 AI 从"加分项"变为"必选项"

| 变化维度 | 过去 | 现在 |
|---------|------|------|
| AI技能 | 可有可无 | 几乎所有头部JD都有AI要求 |
| 编程工具 | 手写代码 | Cursor/Copilot/LangChain等AI工具熟练使用已成本能 |
| 策略生产方式 | 研究员写因子 | LLM自主因子挖掘+人工筛选 |
| 面试重点 | "怎么写代码" | "怎么判断策略质量" |
| 价值分水岭 | 实现能力 | 研究品味+实验设计能力 |

**具体技术趋势:**
- LLM微调和部署（vLLM/DeepSpeed）成为高优先级技能
- PyTorch深度学习、GPU集群分布式训练（K8s/Ray）需求增长
- FPGA低延迟优化和国产AI芯片（昇腾/海光）适配成为新兴方向
- 九坤已开源代码大模型 IQuest-Coder-V1，LLM/RL/DL 全面渗透量化全流程

### 3.3 C++仍是第一语言

- 量化开发 JD 中 C++ 出现频次是 Python 的 **1.9 倍**
- C++ 供给稀缺, 薪资溢价显著
- Rust 开始在量化系统中构成潜在竞争（如 nanobook 引擎 600万笔/秒撮合）
- **C++ 强的人比 Python 强的人更有议价权**

### 3.4 实习薪资真实分布(更新版)

过去的"100-400 vs 2000-3000"二分法过于粗略, 实际分布：

| 机构级别 | Python方向 | C++方向 |
|---------|-----------|---------|
| 头部(顽岩滚石/九坤/凯读) | 800-2000元/天 | 800-2000元/天 |
| 中等(启林/宽德) | 400-800元/天 | 600-1200元/天 |
| 小型机构 | 150-400元/天 | 300-600元/天 |

C++岗普遍比 Python 岗高 20-30%，头部机构 C++ 方向日薪可达 2000+。

### 7.4 本轮新增结论

1. **高薪量化开发的核心不是Python,而是C++系统能力。** Python用于数据、研究、回测、自动化,但高频/交易系统/基础设施岗位几乎都把C++、Linux、并发、低延迟放在核心位置。
2. **"交易系统端到端经验"比泛泛后端项目更贴近JD。** 招聘方想看到行情接入、信号、下单、订单状态、成交回报、风控、对账、监控和故障处理。
3. **数据工程是量化开发的第二入口。** 对本科生更友好的切入点是金融数据清洗、质量监控、回测数据适配、因子计算工具,再逐步转交易系统。
4. **AI确实进入JD,但目前更像加分项/交叉方向。** 头部机构和新岗位会提PyTorch、RAG、FinGPT、K8s/Ray/GPU、AI编程助手,但C++/Linux/算法仍是硬门槛。
5. **实习转正仍是最现实通道。** 实习僧、牛客和校招页反复出现"留用/转正",因此课程应尽早产出可展示项目,而不是等全学完再准备简历。

### 7.5 对当前学习路线的修正建议

| 优先级 | 调整 | 原因 |
|--------|------|------|
| P0 | 阶段1 Python继续压缩到"够用":语法、Pandas/NumPy、数据清洗、可视化、文件/接口、一个股票分析小项目 | JD证明Python是基础工具,不是差异化壁垒。 |
| P0 | 阶段2提前强化C++ + 数据结构算法,所有算法题优先C++实现 | C++/算法是简历筛选和面试硬门槛。 |
| P0 | 阶段4项目从"回测系统"扩展为"回测 + 简易订单/风控/监控链路" | 更贴近真实交易系统JD,可在简历中讲端到端链路。 |
| P1 | 加入Linux性能排障小练习:perf/gdb/top/日志定位/简单压测 | 低延迟岗位反复要求性能测量和优化,不能只会写业务逻辑。 |
