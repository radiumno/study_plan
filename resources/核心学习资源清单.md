# 核心学习资源清单

> 本文件负责“真正进入课程主线的资源”。
>
> `resources/lib/资源库.md` 继续作为大范围候选库和观察列表。GitHub star、播放量和“最新”标签不能替代内容质量判断。

## 一、选择规则

每个阶段最多同时使用:

- 1个主教材或主课程
- 1个官方参考
- 1个项目/练习来源

资源进入主线必须满足:

1. 对应当前阶段能力目标。
2. 顺序清楚，前置要求明确。
3. 有练习、项目或可验证产出。
4. 优先官方、原作者、大学课程或长期维护项目。
5. 不能因为热门、star高或内容多就进入主线。

## 二、阶段1: Python数据闭环

| 角色 | 资源 | 用法 |
|------|------|------|
| 主课程参考 | [CS50P](https://cs50.harvard.edu/python/) | 参考教学顺序、问题集和测试意识 |
| 官方语法参考 | [Python Tutorial](https://docs.python.org/3/tutorial/) | 查证语法和标准库 |
| NumPy主参考 | [NumPy Quickstart](https://numpy.org/doc/stable/user/quickstart.html) | 数组、shape、axis、向量化 |
| Pandas主参考 | [Pandas Getting Started](https://pandas.pydata.org/docs/getting_started/intro_tutorials/) | DataFrame、选择、合并、时间序列 |
| 可视化主参考 | [Matplotlib Tutorials](https://matplotlib.org/stable/tutorials/index.html) | Figure/Axes和基础图表 |
| 金融语境补充 | [QuantEcon Python Programming for Economics and Finance](https://python-programming.quantecon.org/) | 金融数据与Pandas应用，不照搬全套 |

阶段1不再把多个中文长视频同时列为“主力”。需要中文解释时按当天知识点临时补充。

## 三、阶段2: 现代C++与算法

| 角色 | 资源 | 用法 |

## 五、阶段4: 网络、数据库与量化系统

| 角色 | 资源 | 用法 |
|------|------|------|
| 网络课程 | [Stanford CS144](https://cs144.github.io/) | 网络原理和实现思维，按模块选学 |
| 数据库课程 | [CMU 15-445](https://15445.courses.cs.cmu.edu/) | SQL之后理解存储、索引、并发和恢复 |
| 市场微观结构 | 《Trading and Exchanges》 | 订单簿、流动性、滑点和交易机制 |
| 回测架构参考 | [QuantConnect LEAN Engine](https://www.quantconnect.com/docs/v2/lean-engine/getting-started) | 研究其模块边界、事件流和现实模型 |
| 国内交易系统参考 | [VeighNa/vn.py](https://github.com/vnpy/vnpy) | 研究网关、事件引擎、订单与回报模型 |
| AI量化选学 | [Qlib Documentation](https://qlib.readthedocs.io/en/stable/) | 主线达标后选看数据层、工作流和回测 |

LEAN用C#实现，vn.py用Python实现。它们用于架构观察，不是要求照抄语言和代码。

## 六、资源分层

| 层级 | 定义 | 处理方式 |
|------|------|----------|
| 核心 | 当前阶段会进入课程和练习 | 保持少量、稳定 |
| 补充 | 某个知识点需要第二种解释 | 当天按需使用 |
| 项目参考 | 用于观察接口、事件流、测试和文档 | 只拆目标模块 |
| 观察列表 | 新资源、热门仓库、工具合集 | 不直接改变路线 |
| 淘汰 | 失效、重复、营销化或无法验证 | 从主线移除 |

## 七、复核节奏

- 写每个Day: 检查1个官方源 + 1个主课程源。
- 进入新阶段: 重新核验该阶段核心资源。
- 每季度: 检查链接、版本和课程结构，不机械刷新star数。
- 只有新资源明显优于现有核心资源时才替换。
