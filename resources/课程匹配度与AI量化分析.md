# 招聘市场匹配度 & AI+量化调研

> 数据来源: BOSS直聘/猎聘(5月25-31日) + Workflow并行调研(5月31日)
> 核心变化: **AI从加分项变为必选项**, Python基础可压缩, C++战略地位不变

---

## 一, 2026年量化开发市场核心变化

### 1.1 AI全面渗透

2026年5月调研发现量化开发的**价值重心正在转移**:

| 角色转变 | 从 | 到 |
|---------|---|----|
| 策略生产 | 研究员手写因子 | LLM生成因子 + 人工筛选 |
| 编程工具 | 手动编码 | AI辅助编码(Cursor/Claude Code)已成必须 |
| 核心能力 | "How to code" | "What is worth building" |
| 面试重点 | 代码实现能力 | 策略品鉴 + 实验设计能力 |

**具体影响:**
- 九坤开源代码大模型 IQuest-Coder-V1
- LLM微调部署(vLLM/DeepSpeed)成为高优先级技能
- PyTorch深度学习进入量化开发JD
- Cursor/Copilot/LangChain熟练使用已成为硬性要求

### 1.2 竞争强度

| 指标 | 数据 |
|------|------|
| 头部实习录取率 | 0.2% (30个岗/15000份简历) |
| 正式岗录取率 | 0.2% (50个岗/24000份简历) |
| 低于哈佛录取率 | 哈佛本科 3% |
| 竞赛背景员工占比 | 头部机构核心成员 >60% |
| 学历通胀 | 头部普遍偏好硕博, 本科名额持续压缩 |

### 1.3 对学习者意味着什么

| 变化 | 应对 |
|------|------|
| 纯代码能力不再差异化 | 阶段1 Python可压缩到5周, 更早进入C++阶段 |
| AI工具熟练度是基本盘 | 日常使用Claude Code/Cursor, 不是"要不要学"而是"怎么用得更好" |
| 策略思维成为分水岭 | 阶段4开始注重"判断力"训练, 不止是实现能力 |
| 竞赛经历权重上升 | 数模国赛/美赛保持, 尽早接触WorldQuant |

## 四, 实习薪资与就业前景

### 4.1 实习薪资真实分布

| 级别 | 公司 | Python方向 | C++方向 |
|------|------|-----------|---------|
| 头部 | 顽岩/九坤/凯读 | 800-2000元/天 | 800-2000元/天 |
| 中等 | 启林/宽德 | 400-800元/天 | 600-1200元/天 |
| 小机构 | 全频/念觉 | 150-400元/天 | 300-600元/天 |

C++岗普遍高20-30%, 但非早前的"5-10倍"差距。头部机构两种语言薪资趋同。

### 4.2 应届薪资全景

- **行业区间:** 23K ~ 60K/月 (应届)
- **头部区间:** 40-80万/年 (九坤/幻方/衍复)
- **中位数:** 约30-40K/月
- **远高于互联网:** 互联网后端应届 20-35K

### 4.3 关键信号

1. **本科能进但越来越难** — 学历通胀持续, 建议尽早参与竞赛积累筹码
2. **实习转正是核心通道** — 几乎所有实习标注"可转正"
3. **C++决定薪资上限** — C++方向议价权远高于Python方向
4. **AI是新的差异化维度** — 2026年JD新增, 需要提前布局

## 五, 总结建议

1. **Python基础加速到5周** (原7周), 更早进入C++
2. **日常使用Claude Code/Cursor**作为默认开发工具
3. **保持数模国赛/美赛**, 尽早接触WorldQuant Challenge
4. **C++必须死磕** — 这是在量化开发中比其他候选人强的核心武器
5. **阶段4增加AI/ML基础** — PyTorch入门 + LLM基础概念
6. **大二下实习投递** — 目标中型量化私募C++方向
