# 知识库使用说明

这个 vault 是 Claude Code（我）的跨会话记忆系统。

## 工作方式

- **你说「记住xxx」** → 我立即写进 vault
- **你问「还记得xxx吗」** → 我翻 vault 找
- **新会话开始** → 我先读 vault，恢复记忆

## 目录结构

| 目录 | 用途 |
|------|------|
| `量化知识点/` | 重要的量化概念、代码技巧、最佳实践 |
| `课程记录/` | 每课学到了什么、用户掌握程度、薄弱项 |
| `坑与教训/` | 踩过的坑、错误代码、为什么不 work |
| `资源备忘/` | 推荐的工具、教程、GitHub 项目 |
| `会话记录/` | 每轮会话干了什么、关键决策 |

## 使用规则

1. 每条笔记带 `date` 和 `tags` 元数据
2. 知识点尽量关联已有笔记（`[[链接]]`）
3. 坑与教训标注原因和解决方案
