# 写课程流程

> 每次用户说"开始今天的学习" / "开始写课" / "继续" 时, 按此流程执行.
> 参考: `主脉络.md` | `阶段X_分脉络大纲.md` | `memory/`

---

## 流程总览

```mermaid
flowchart TD
    A[用户说"开始学习"] --> B[读主脉络 + CLAUDE.md 定位进度]
    B --> C{细脉络存在且吻合?}
    C -->|没有细脉络| D[走 写脉络流程 创建细脉络]
    C -->|对不上主脉络| D
    C -->|是| E[加载记忆规则]
    D --> E
    E --> F[依赖检查: 本day知识点全有前置?]
    F --> G{通过?}
    G -->|漏了前置| H[补前置: 修改之前day或本day追加教学]
    H --> F
    G -->|通过| I[写教程 dayXX]
    I --> J[更新进度: 主脉络 + 细脉络 + CLAUDE.md]
    J --> K[问用户是否 commit]
```

## 步骤详解

### Step 1: 定位进度

读两个文件确定当前位置:

- `resources/主脉络.md` -- 当前阶段/当前 day
- `.claude/CLAUDE.md` 的 `## 当前状态` 节

输出: 明确的 "当前是阶段X 第Y天, 接下来该学什么"

### Step 2: 核对细脉络

读 `docs/plans/阶段X_分脉络大纲.md`

- **没有这个文件?** -> 停, 先走"写脉络流程"创建它
- **有, 但内容对不上主脉络?** (比如主脉络说这周学Python, 细脉络写的是C++) -> 停, 更新细脉络
- **有且吻合?** -> 以细脉络的当天安排为准写课程

### Step 3: 加载记忆规则

扫 MEMORY.md, 确认以下规则全部加载:

| 记忆 | 约束 |
|------|------|
| english-punctuation | 代码文件禁用中文全角标点 |
| teaching-explain-every-step | 每行代码/每参数逐一拆解 |
| teaching-check-exercises | 提示前核对已教知识点 |
| curriculum-prerequisite-check | 当天依赖清单 vs 已教清单做 diff |
| exercise-design-pattern | 按难度调练习数 |
| never-fabricate | 做不到明说, 不编造 |
| daily-progress-display | 教程开头显示进度条 |
| sub-threads-research-based | 教学有依据, 不凭空编 |

### Step 4: 依赖检查

写教程前, 列一张依赖清单:

```markdown
## 本 day 依赖清单
| 依赖项 | 类型 | 首次出现 | 确认覆盖 |
|--------|------|----------|----------|
| list | 基础类型 | Day 02 | 已教 |
| set | 基础类型 | Day 04 | 本 day 教 |
| open/with | 语法 | Day 04 | 本 day 教 |
```

- 每个新知识点后的练习不能用到还没教的语法
- 如果某知识点是前置但漏了 -> **先补到之前的 day**, 再继续

### Step 5: 写教程

按细脉络大纲的当天安排 + 记忆规则写 dayXX 文件:

结构:
```
## [Day X] 标题

### 教学部分
- 知识点讲解 (逐行拆解, 每参数说明)
- Python vs C++ 对比 (利用 C++ 接触背景)
- 类比量化开发场景说明用途

### 练习部分
- 紧跟在知识点后, 不堆末尾
- 难度递进: 填空 -> 补全 -> 完整实现
- 综合练习: 跨当天知识点
```

### Step 6: 更新进度

修改以下文件的状态标记:

- `resources/主脉络.md` -- 当前 day 的完成状态
- `docs/plans/阶段X_分脉络大纲.md` -- 对应 day 标记完成
- `.claude/CLAUDE.md` -- 更新 `## 当前状态`

### Step 7: 问 commit

每天学完问用户是否要 commit.
格式: `dayXX: 简短描述`

## 举例

> 用户: "开始今天的学习"
> 我: 读主脉络 -> 当前 Day 04 set+文件+异常 (练习待续)
> 读细脉络 -> Day 04 安排了: set 教学 -> 异常处理 -> 文件 I/O -> 综合
> 读记忆 -> 英文符号, 逐行拆解, 前置依赖...
> 依赖检查 -> set 是新增, 文件 I/O 新语法, 异常新语法, 全部在 day04 内首次教, OK
> 写教程 -> 发现 set 部分已写, 直接让用户继续练习
> 用户写完练习 -> 更新进度
