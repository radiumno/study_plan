## 6. Week 4: 集成项目

### 项目结构

```
DataReader -> ReplayQueue -> Processor -> Metrics -> Report
```

### 必做

- 单线程正确版本
- 多线程版本
- 测试和样例数据
- benchmark对比
- ASan/UBSan/TSan检查
- README和架构图

### 优化纪律

1. 先测量基线。
2. 提出一个可证伪假设。
3. 一次只改一个变量。
4. 保存结果和环境。
5. 结果不稳定时不下结论。

### 选做

- 固定大小对象池
- 无锁队列调研
- pybind11接口

选做不影响阶段通过。
