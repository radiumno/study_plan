## 3. Week 1: 现代C++特性

### 教学内容

| 知识点 | 参考资源 | 量化场景 |
|--------|---------|---------|
| unique_ptr | Cherno C++ #99-101 | 订单资源管理, 自动释放 |
| shared_ptr/weak_ptr | Cherno C++ #102-104 | 共享数据: 行情订阅 |
| 移动语义 | Cherno C++ #77-79 | 避免大对象拷贝(回测数据) |
| 右值引用/完美转发 | 《Effective Modern C++》Item 23-30 | 高性能库设计 |
| lambda + auto | Cherno C++ #66-68 | 自定义排序/回调 |
| constexpr/if constexpr | cppreference | 编译期计算 |

### 练习
- 用 unique_ptr 管理交易订单, 对比 raw ptr
- 实现一个 Stock 类: 包含移动构造/移动赋值
- 用 lambda 排序股票池 (按PE/按市值)
