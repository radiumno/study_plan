## 4. Block A: Linux、调试与性能

### 核心内容

- 进程、文件、权限、管道、信号基础
- Shell脚本和日志处理
- CMake Presets、构建类型、CTest
- GDB/LLDB、core dump
- perf/time/top或平台替代工具
- 日志、压测和故障复盘

### 练习

- 为阶段3项目增加日志和构建预设。
- 制造崩溃、内存错误和性能退化并定位。
- 输出一份“现象-假设-证据-修复-回归”报告。

### 验收

能独立定位至少3类问题，不只会运行命令。

## 5. Block B: 并发与网络

### Week 5-6: 并发巩固

- 线程池概念
- 有界队列、背压
- condition_variable、atomic
- 锁粒度、竞态、死锁

### Week 7-8: 网络与协议

- TCP/UDP基础
- socket生命周期
- 阻塞/非阻塞、超时、重连
- 消息边界、序列化、心跳

### 项目: TCP行情接收器

```
MarketDataServer -> SocketClient -> Decode -> Queue -> Processor -> Metrics
```

**必须覆盖:**

- 正常消息
- 半包/粘包的概念和处理
- 断线、超时、重连
- 队列满或消费者变慢
- 日志和延迟统计

## 6. Block C: SQL、数据质量与交易业务

### SQL与数据

- 关系模型、主键、索引
- SELECT/JOIN/GROUP BY/窗口函数
- 事务和并发的基本概念
- 数据完整性、迟到数据、重复数据
- 行情数据质量表和检查任务

### 市场微观结构

- 限价单、市价单、订单簿
- 撮合、部分成交、撤单
- 滑点、手续费和市场冲击
- T+1、涨跌停、停牌等市场规则

### 订单状态机

```
Created -> Submitted -> PartiallyFilled -> Filled
                    \-> Cancelled
                    \-> Rejected
```

### 验收

- SQLite/PostgreSQL任选其一完成行情库。
- 有数据质量检查和异常样本。
- 订单状态转换有测试。

## 7. Block D: C++事件驱动回测引擎

### 范围

```
DataFeed -> EventQueue -> Strategy -> Portfolio -> ExecutionModel -> Metrics
```

### 必做功能

- CSV/数据库行情读取
- 均线或动量策略
- MarketData/Signal/Order/Fill事件
- 仓位、资金和交易成本
- 累计收益、最大回撤、基础风险指标
- 结果报告和样例

### 工程要求

- C++17/20、CMake、GoogleTest
- 模块接口和所有权清楚
- 单元测试 + 端到端测试
- benchmark只测有意义的热点
- 明确禁止未来函数

### 不做

- 实盘接入
- 大规模参数搜索
- 多资产复杂组合
- “高频”或“低延迟”营销式命名

## 8. Block E: C++交易链路模拟器

### 范围

```
MarketData -> Strategy -> Risk -> OrderManager -> ExchangeSimulator
                                           -> Fill -> Portfolio -> Monitor
```

### 必做功能

- 模拟行情源
- 下单、撤单、拒单
- 部分成交与完整成交
- 仓位/金额/价格边界风控
- 成交回报、持仓和资金更新
- 断线、重连、重复回报或乱序回报的最小处理
- 日志、监控指标和故障复盘

### 验收

- 至少一个正常场景和三个异常场景。
- 状态机测试完整。
- 能用10分钟讲清一笔订单的全生命周期。
