### Week 1-2: Python→C++过渡 (适应期)

> 从Python到C++的最大挑战不是语法, 而是思维方式转变.
> 前2周不做LeetCode, 先让身体记住C++的节奏.

| Python习惯 | C++对应 | 适应要点 |
|-----------|---------|---------|
| `x = 5` | `int x = 5;` | 静态类型, 必须声明 |
| `a, b = b, a` | `std::swap(a, b)` | 没有多变量赋值 |
| `for x in list:` | `for(auto x : vec)` | 范围for类似, 但注意值/引用 |
| `list.append(x)` | `vec.push_back(x)` | STL容器有专门方法 |
| `d.get(k, default)` | `map.count(k) ? map[k] : default` | map操作更底层 |
| `with open(f) as f:` | `std::ifstream f(fname)` | 资源管理需要RAII |
| `try/except` | `try/catch` | 语法类似 |

| 知识点 | 参考资源 | 说明 |
|--------|---------|------|
| 类型/常量/constexpr | 黑马程序员C++ | **对比Python理解静态类型** |
| 指针与引用 | Cherno C++ | 引用 vs 指针, 左值/右值 |
| 函数重载/默认参数 | 黑马 | C++特性 |
| 动态内存 new/delete | Cherno | **对比Python自动GC** |
| 面向对象回顾 | 黑马 | class/继承/虚函数/多态 |
| 异常处理 try/catch | 黑马 | 对比Python异常 |

**练习:** 从Python翻译到C++ (10个小程序)
1. 变量声明 + 基本运算 (对比动态 vs 静态)
2. 字符串拼接和格式化
3. 数组遍历 + 求和 (Python list → C++ vector)
4. 实现一个函数, 输入价格返回涨跌判断
5. 用struct包装股票数据 (对比Python dict)
6. 读写一个CSV文件 (对比Python with open)
7. 实现一个简易计算器 (函数 + switch)
8. 用指针修改数组元素 (理解指针)
9. class封装银行账户 (对比Python class)
10. 综合: 用C++重写阶段1 Day06的股票数据管理器基本功能
