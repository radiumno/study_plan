## 一、阶段5目标

目标不是“必须拿到某家量化实习”，而是获得一段可验证的真实协作经历。

### 路径优先级

| 优先级 | 路径 | 合格产出 |
|--------|------|----------|
| A | 量化开发/交易系统/研究平台实习 | 真实模块、复盘、推荐或证明 |
| B | 券商IT/FinTech/C++系统/数据平台实习 | 生产工程经验和协作证据 |
| C | 实验室、老师项目、开源协作 | PR、Issue、模块交付、评审记录 |
| D | 自主项目冲刺 | 版本发布、用户反馈、性能/可靠性报告 |

没有A时立即切B/C，不空等，不把“没进量化”解释为阶段失败。

## 二、阶段5准备

| 项 | 截止 | 验收 |
|----|------|------|
| 回测引擎 | 2027.05 | 可运行、测试、README、演示 |
| 交易链路模拟器 | 2027.06 | 正常+异常场景 |
| 简历 | 2027.03起迭代 | 一页、可量化证据 |
| 算法 | 持续 | 限时稳定，不追求虚高题数 |
| 投递表 | 2027.02起 | 公司、岗位族、日期、结果、复盘 |

## 三、阶段5执行

### 如果拿到实习

| 周期 | 目标 | 记录 |
|------|------|------|
| 第1周 | 环境、代码库、业务链路 | 术语和依赖图 |
| 第2-3周 | 完成第一个小任务 | PR/测试/反馈 |
| 第4-6周 | 独立负责模块 | 设计与故障复盘 |
| 第7-8周 | 收尾与表达 | 可公开摘要、推荐、简历更新 |

### 如果未拿到实习

执行8周替代计划:

1. 对一个目标开源项目完成模块级拆解。
2. 修复Issue或提交至少一个可评审PR。
3. 发布回测引擎或交易链路v1.0。
4. 做2轮模拟面试和简历迭代。
5. 为秋季日常实习继续投递。

## 四、阶段6定位

阶段6只做三件事:

1. 深挖已有项目和系统能力。
2. 根据实际岗位样本选择一个分支补强。
3. 同时处理考研与求职，不无边界开新坑。

## 五、定向分支

### 分支A: 交易系统/低延迟

- 缓存、内存布局、分支预测
- 高性能网络、序列化、时间测量
- 更严格的benchmark和故障恢复

### 分支B: 研究平台/数据工程

- PostgreSQL/ClickHouse
- 数据质量、任务调度、可追溯性
- 分布式数据处理和研究工作流

### 分支C: C++系统/FinTech后端

- 服务端工程、RPC、数据库、消息队列
- 系统设计和可靠性

### 分支D: AI基础设施/工具

- 只有实际投递目标明确时选择
- AI基础设施偏C++/Python/GPU/分布式
- AI应用偏评估、工具调用和后端工程

每次只选一个分支，8-12周后依据面试反馈决定是否继续。

## 六、算法与面试

### 目标口径

- 秋招前200-250道高质量独立题。
- 核心错题至少间隔重做2-3次。
- 每月2次限时模拟。
- 项目和系统设计回答必须建立在真实实现上。

### 面试模块

| 模块 | 验收 |
|------|------|
| 算法 | 限时、复杂度、边界 |
| C++ | 所有权、容器、并发、内存模型 |
| 系统 | Linux、网络、数据库、性能 |
| 量化 | 回测偏差、订单状态、风控、微观结构 |
| 项目 | 30分钟深挖不过度包装 |
| 行为 | 能说明失败、反馈和改进 |

## 七、项目集

最终简历只保留2-3个最强项目:

| 项目 | 证明能力 |
|------|----------|
| C++回测引擎 | 事件架构、数据、测试、量化业务 |
| C++交易链路模拟器 | 网络/并发/状态机/风控/可靠性 |
| 市场数据回放或数据平台 | 性能或数据工程分支 |

Python阶段项目作为早期证明，不必永久占据简历核心位置。

## 八、考研协同

考研详细安排以 `docs/plans/考研备考对照表.md` 为准。

原则:

- 408与系统学习共享知识，不共享全部练习时间。
- 数一和概率统计服务量化理解，但不硬塞进工程Day。
- 大三下必须明确每周技能、考研、投递的真实时间预算。

## 十、失败条件与修正

| 信号 | 修正 |
|------|------|
| 项目越来越多但都讲不深 | 停止新项目，合并和重写 |
| 刷题数上涨但限时仍失败 | 降低新题，增加间隔重做 |
| 只投头部量化无反馈 | 扩展到研究平台、FinTech和C++系统岗 |
| 考研挤压技能到不可执行 | 重新做周容量预算 |
| AI分支拖慢主线 | 立即暂停AI，回到目标岗位证据 |
