## 阶段5: 第一份实习 (大二暑假 7-8月)

### 定位

这不是学习阶段, 而是应用阶段. 目标是 **拿到真实量化开发经历**.

### 实习前 (6月, 与阶段4 Part 5重叠)

| 任务 | 截止 | 产出 |
|------|------|------|
| GitHub仓库完善 (README/文档) | 6月底 | 3+项目 |
| 一页纸简历 (找老师/学长改) | 6月底 | PDF |
| LeetCode 200题 (阶段4目标) | 6月底 | 刷题记录 |
| C++八股通读 (智能指针/多线程/内存) | 6月底 | 脑图 |
| 回测引擎+交易链路模拟器复盘 | 6月底 | 架构图+故障复盘文档 |

### 实习投递分层

| 时间 | 可以投什么 | 不建议投什么 | 原因 |
|------|------------|--------------|------|
| 大二下2-3月 | 小私募数据/开发实习、FinTech、券商IT | 头部高频核心C++岗 | 项目还在成型,先拿面试反馈 |
| 大二下4-6月 | 实习友好量化私募、交易系统/数据平台实习 | 只看研究员/顶级alpha岗 | 目标是拿第一段开发经历 |
| 大二暑假后 | 用实习经历继续投更好平台 | - | 第一段经历是简历跃迁点 |
| 大三上/下 | 启林/宽德/顽岩/九坤/幻方等更高层级 | - | 此时需要交易引擎、低延迟、LeetCode 350-500题支撑 |

### 实习中 (7-8月)

| 周 | 目标 | 动作 |
|----|------|------|
| 第1周 | 熟悉环境 | 搭开发环境, 读代码库, 问同事 |
| 第2-3周 | 第一个任务 | 从小的数据清洗/脚本开始 |
| 第4-5周 | 独立任务 | 争取独立负责一个模块 |
| 第6-7周 | 深入 | 了解业务流程, 主动要任务 |
| 第8周 | 收尾+总结 | 写实习报告, 争取推荐信 |

**产出:**
- 一段真实量化开发经历 (简历核心卖点)
- 实习证明 + 可留用的推荐信
- 明确大三方向 (继续量化 or 互联网保底)

## 阶段6: 冲刺 + 秋招 (大三 2027.9-2028.6)

### 定位

最后一年, 两线作战: **技能收尾 + 考研冲刺 + 秋招保底**

### 总体时间线

```
大三上 (2027.9-2028.1):
├── 技能收尾: C++低延迟/分布式/交易系统
├── 考研: 408真题一轮 + 数一强化 + 英语单词
├── 面试: 刷LeetCode 350题
│
大三下 (2028.2-6):
├── 技能: 交易引擎完善 + 低延迟优化 + AI工具化补充
├── 考研: 408真题二轮 + 数学强化
├── 政治: 开始(每天30min)
├── 投递: 海投暑期实习(3-4月), 面试(5-6月)
│
大四上 (2028.9-12):
├── 考研冲刺 (9-12月)
├── 秋招保底 (9-11月投递)
│
大四下 (2029.1-3):
├── 考研复试/调剂
└── 春招保底
```

### Part 1: C++进阶 (大三上)

| 主题 | 内容 | 参考 |
|------|------|------|
| 低延迟优化 | 内存对齐, Cache友好, SIMD | 《C++ High-Perf》 |
| 分布式系统 | ZeroMQ, 序列化, RPC | 《分布式系统概念》 |
| 交易系统架构 | 订单管理, 风控, 行情接入 | 开源项目(muduo/vnpy) |

**核心项目:** 用C++实现简易交易引擎 (订单簿+撮合+风控+监控)
- 参考: vnpy CTPSocket 架构, QuantConnect/Lean 事件驱动
- 必须能讲清: 行情进入系统后如何生成订单、如何过风控、如何更新持仓资金、如何处理拒单/部分成交/连接断开
