# 练习依赖校准规则

> 用途: 防止练习题要求使用还没教过的语法、库、API 或工程方法。写课时每道练习都必须先做依赖校准。

---

## 一,硬规则

1. 必做练习只能依赖以下内容:
   - 之前 day 已经教过的知识
   - 当天前面知识块已经讲过的知识
   - 该练习正上方刚刚讲完的知识点
2. 知识块总练习可以使用本知识块之前所有内容,但不能使用后面才讲的内容。
3. Day 综合练习可以使用当天已讲内容 + 历史已学内容,但不能偷偷引入新技术。
4. 找 bug 题也不能出现未教过的关键技术; bug 可以难,依赖不能越级。
5. 未教内容只能放在“选做/预告”题里,且不能作为进入下一天的门槛。

一句话: 题目可以综合,但依赖不能穿越。

---

## 二,写题前依赖矩阵

写每道练习前,先在内部过这张表:

| 项 | 必填 |
|----|------|
| 练习编号 | 例如 2.1.3 / 块练习2 / Day综合 |
| 目标能力 | 这题到底练什么 |
| 必用技术 | 想完成这题必须会哪些语法/库/API |
| 已教来源 | Day X / 本节知识点 X.X |
| 是否有替代解 | 如果用户不用预期方法,能否用已学方法完成 |
| 结论 | 保留 / 前移教学 / 降级题目 / 改选做 / 删除 |

如果“必用技术”找不到已教来源,这题不能作为必做题。

---

## 三,题型依赖边界

| 题型 | 允许依赖 | 禁止依赖 |
|------|----------|----------|
| 知识点后练习 | 历史已学 + 刚讲知识点 | 后面才会讲的函数/API |
| 知识块总练习 | 历史已学 + 本知识块已讲内容 | 下一个知识块内容 |
| Day 综合练习 | 历史已学 + 当天全部已讲内容 | 未教的新库/新框架/新工程结构 |
| 复习题 | 只用过去 day 已教内容 | 当天新内容 |
| 选做题 | 可以少量预告未教内容 | 作为必做验收或进入下一天条件 |

---

## 四,发现越级时怎么处理

按这个顺序处理:

1. 能用已学方法完成: 改题面约束,保持必做。
2. 当前知识点确实必须用: 把知识点讲解前移到练习之前。
3. 技术有价值但不该今天学: 改成选做/预告。
4. 技术不服务阶段目标: 删除。

不要用“提示”偷偷教新技术。提示只能点方向,不能补一整块没教过的知识。

## 六,写完后的自检

写完课程后逐题检查:

- 每道必做练习是否能只用已教内容完成
- 练习位置是否在对应知识点之后
- 复习题是否没有使用当天新内容
- Day 综合是否没有偷塞未讲技术
- 选做题是否明确不影响进度
- 提示是否没有变成“补课式答案”
