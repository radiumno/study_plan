## 一、408 计算机学科专业基础

### 数据结构 (45分) — 与阶段2完全重叠

| 408考点 | 技能对应 | 覆盖阶段 |
|--------|---------|---------|
| 线性表(顺序/链式) | C++ STL vector/list | 阶段2 |
| 栈、队列 | C++ STL stack/queue | 阶段2 |
| 树与二叉树 | 算法题基础 | 阶段2 |
| 图 | 算法题基础 | 阶段2 |
| 查找(二分/哈希) | 算法题高频 | 阶段2 |
| 排序(8种) | 算法题高频 | 阶段2 |

> **结论:** 学C++数据结构时自然覆盖, 只需要考前刷408真题适应题型.

### 计算机组成原理 (45分) — 阶段3/6部分重叠

| 408考点 | 技能对应 | 覆盖阶段 |
|--------|---------|---------|
| 数制与编码 | C++数据类型底层 | 阶段3(C++深入) |
| 存储器层次(Cache/虚拟) | 低延迟/内存优化 | 阶段6(低延迟) |
| 指令系统 | 汇编级优化 | 阶段6 |
| CPU结构 | 性能调优理解 | 阶段3 |
| 总线与I/O | 网络/外设交互 | 阶段4 |

> **部分覆盖:** Cache/虚拟内存等与C++性能优化直接相关, 但计组有约50%内容(指令流水线/CPU结构)在技能学习中不会深入, 需要考前单独刷.

### 操作系统 (35分) — 与阶段4高度重叠

| 408考点 | 技能对应 | 覆盖阶段 |
|--------|---------|---------|
| 进程管理/调度 | 多线程编程 | 阶段4 |
| 同步与互斥 | 锁/条件变量/信号量 | 阶段4 |
| 内存管理 | 内存池/RAII | 阶段3-4 |
| 文件系统 | Linux文件操作 | 阶段3 |
| 设备管理 | I/O多路复用 | 阶段4 |

> **结论:** 学多线程/Linux时自然覆盖, 约90%重叠.

### 计算机网络 (25分) — 与阶段4部分重叠

| 408考点 | 技能对应 | 覆盖阶段 |
|--------|---------|---------|
| TCP/UDP协议 | Socket编程 | 阶段4 |
| IP/路由 | 网络基础 | 阶段4 |
| HTTP/应用层 | REST API/数据采集 | 阶段4 |
| 网络安全 | 加密/认证 | 阶段4(轻) |

> **部分覆盖:** Socket编程覆盖传输层, 但网络层/链路层/网络安全需考前补充.

### 408 总重叠率估算

| 科目 | 与技能重叠 | 考前需补 |
|------|-----------|---------|
| 数据结构 | 95% | 少量题型适应 |
| 操作系统 | 90% | 少量概念题 |
| 计算机网络 | 60% | 网络层+安全 |
| 计算机组成原理 | 40% | 指令流水线/CPU |

> **结论:** 408约70%内容在技能学习中自然覆盖, 考前2-3个月刷真题补剩余30%.

## 二、数学一

### 高等数学 (~60%) — 与AI数学部分重叠

| 考点 | 技能对应 | 覆盖阶段 |
|------|---------|---------|
| 极限/连续 | 基础 | 本科课程 |
| 导数/微分 | 优化算法基础 | 本科课程 |
| 积分 | 概率基础 | 本科课程 |
| 级数 | 时间序列基础 | 本科课程 |
| **多元微分** | **神经网络梯度** | AI辅线+本科 |
| **微分方程** | 随机过程/衍生品定价 | 阶段6 |

> 本科课程覆盖大部分, AI辅线加强多元微分和梯度理解.

### 线性代数 (~20%) — 与AI/量化高度重叠

| 考点 | 技能对应 | 覆盖阶段 |
|------|---------|---------|
| 矩阵运算 | NumPy矩阵/Pandas | 阶段1/Part2 |
| 线性方程组 | 回归分析 | 本科 |
| 特征值/特征向量 | PCA/因子模型 | AI辅线 |
| 向量空间 | 深度学习表示 | AI辅线 |
| **二次型** | **投资组合优化** | 阶段6 |

> 这是重叠度最高的一门, 学NumPy/Pandas时就在用.

### 概率论与数理统计 (~20%) — 与量化高度重叠

| 考点 | 技能对应 | 覆盖阶段 |
|------|---------|---------|
| 随机变量/分布 | 收益率分布建模 | 阶段4+ |
| 期望/方差 | 风险评估 | 阶段4 |
| 大数定律/中心极限 | 回测置信度 | 阶段4 |
| 参数估计/假设检验 | 因子有效性检验 | 阶段4+ |
| 回归分析 | 因子模型构建 | 阶段4+ |
| **随机过程** | **期权定价/高频** | 阶段6 |

> 概率统计是量化的命根子, 技能学习会反复用到.

### 数学一总重叠率

| 科目 | 与技能重叠 | 考前需补 |
|------|-----------|---------|
| 高等数学 | 60% | 级数/微分方程/曲线积分 |
| 线性代数 | 95% | 极少需要专门补 |
| 概率统计 | 90% | 大数定律的证明题 |

> **结论:** 数学一约70-80%在技能+本科课程中覆盖, 考前刷真题补计算速度和证明题.
