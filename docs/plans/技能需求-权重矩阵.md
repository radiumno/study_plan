## 权重对课程的直接影响

### 阶段1 Python 调整建议

| 调整 | 原因 |
|------|------|
| Pandas 教学从 2天→3天 | 岗位需求 80%+, Python 技能中最核心 |
| 增加类型注解教学 | 2026年新趋势, 量化代码质量关键 |
| 增加 pytest 基础 | 40%+ 岗位要求测试能力 |
| Day 07 前补控制流回顾 | 修复 Day 01 重大教学缺口 |
| 日常融入 AI 工具链 | AI是提效工具和保底加分,不作为阶段1主线 |

### 后续阶段规划调整

| 调整 | 原因 |
|------|------|
| C++ 直接跳到现代C++ (跳过C-style) | 岗位要求C++11/17/20 |
| 阶段4 新增交易链路模拟器 | JD反复要求行情接入、订单状态、风控、成交回报、监控、对账 |
| 阶段3-4 新增性能排障练习 | 低延迟和生产问题定位是C++量化开发硬需求 |
| 阶段4 AI调整为工具化25% | RAG/Agent有用,但不能挤占C++交易系统主线 |
| 阶段6 低延迟优化建立在阶段4交易链路上 | 头部私募必备差异化技能 |
