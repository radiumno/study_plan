## 6. 当前与后续逐日计划

### Day 11: Matplotlib可视化

**状态:** 学习中

**唯一主目标:** 把数据表转换成可解释的策略观察图。

**内容:**

- scatter/annotate

**验收:**

- 完成知识块3练习和Day综合。
- 生成价格、均线、成交量、买卖点图。
- 能解释图中趋势、量能和信号滞后。

### Day 11R: 数据处理闭环复习

**类型:** 强练习课

**时间:** 2.5-3小时

**新概念:** 0

**任务链:**

1. NumPy构造收益率矩阵。
2. Pandas清洗、时间索引、rolling和合并。
3. Matplotlib生成价量与信号图。
4. 写出数据问题和图表结论。

**验收:** 一道不看答案完成的数据管道综合题；薄弱点进入交接。

### Day 12: Python工程化基础

**类型:** 工具与工程课

**时间:** 2.5-3小时

**前置:** Day 05模块、Day 06项目、Day 11R通过

**核心内容:**

- Git最小工作流: status/diff/add/commit/branch
- 函数参数与返回值的基础类型注解
- pytest基础: arrange-act-assert、`assert`、测试文件组织

**练习范围:**

- 给已有分析函数补类型注解。
- 为收益率/均线/清洗函数写4-6个测试。
- 用分支完成一次小改动并检查diff。

**验收:** 一个带类型注解和pytest的最小分析模块；测试全过；有清晰提交记录。

**后移:** rebase、复杂mock、property-based testing。

### Day 13: 单一数据源采集与清洗

**类型:** 数据管道课

**时间:** 3小时

**前置:** Pandas、文件I/O、异常、pytest

**核心内容:**

- Baostock最小调用流程
- 字段类型、日期、排序、重复、缺失处理
- 数据契约: 必需列、唯一键、时间范围、空值规则

**练习范围:**

- 拉取1只股票，再扩展到3只。
- 统一字段和类型。
- 保存清洗后的CSV。
- 用Day 12的pytest验证数据契约。

**验收:** 3只股票的清洗CSV + 数据质量测试。

**选做:** 观察另一个数据源字段差异。

**后移:** requests通用HTTP、多数据源自动降级、异步采集。

### Day 14: 本地Pandas回测基础

**类型:** 综合应用课

**时间:** 3小时

**前置:** Day 08-13全部通过

**核心内容:**

- 信号、持仓、策略收益
- 手续费/滑点的最小模型
- 累计收益和最大回撤
- 未来函数、数据对齐和过拟合的基本边界

**练习范围:**

- 双均线信号与持仓。
- 加入最小交易成本。
- 输出策略与基准曲线。
- 解释最大回撤和信号滞后。

**验收:** 本地可复现回测脚本和结果图。

**选做平台对照:** 聚宽或米筐30-45分钟，只记录参数、结果和与本地实现的差异。

**后移:** Sharpe深入、参数优化、事件驱动框架、实盘接口。
