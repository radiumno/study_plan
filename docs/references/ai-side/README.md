## 使用边界

- 阶段1不单独学习AI课程。
- 阶段2-3只把AI当作解释、测试和复盘工具。
- 阶段4主线通过后，最多选择一个AI小项目。
- 不因为外部资料章节多就逐章学习。

## 学习方式

1. 先从当前项目问题出发。
2. 只读能解决问题的章节。
3. 跑最小代码。
4. 加测试或评估。
5. 结果写回项目，而不是另开一个无关Demo。
