# 职业方向决策：量化开发 + AI应用 + 考研三线并行

## 决策内容

经过大量数据调研（全国30+所学校、10个城市、6种专业类型），确定的最终方向：

1. **职业第一目标**: AI算法研究员(量化方向)—用深度学习/ML做因子挖掘和策略研发。目标公司：启林/明汯/佳期等百亿私募。需要硕士学历。
2. **职业第二目标**: 量化开发工程师(C++系统/交易系统/低延迟)。本科学历即可，实习转正是核心通道。
3. **职业保底方向**: AI应用开发工程师(LangChain/RAG/Agent)。2025年7.2万个AI岗位，全行业需求。
4. **学历路径**: 考研优先(华科计算机315分/105人/3.9万/985 > 武大计算机数二英二/2年 > 北航全国最低310)。考研内容80%与技能学习重叠。
5. **考研vs Offer冲突解法**: 考研12月考，春招3月拿Offer保底，时间上完全错开，不冲突。
6. **时间分配**: 量化60% + AI40%（数据加权计算AI岗位多占55%，但量化学习曲线更陡占时间更多）。
7. **核心原则**: 你学的技能=你考研的内容(408/数一/英一)。唯一额外考研内容是政治。
