# 练习区必须留空

**错误：** Day 05 教程的每个练习 `# ↓ 你的代码 ↓` 下方都写好了完整答案（import语句、循环逻辑、函数实现等），用户完全没有做题空间。

**为什么犯：**
- **知识的诅咒** — 我知道答案，写出来太顺手，忘了这是给用户做的
- **误解 `↓ 你的代码 ↓` 含义** — 把它当成了"参考答案放这里"，但实际意思是"你在这里写"
- **验证漏洞** — 跑通脚本检查了语法，没反向检查"练习区是不是空着的"
- **Day 04 的干扰** — Day 04 有些练习下面也写了部分代码，误以为这是惯例

**修复：** 全部答案已删除，只留题目描述和必要的脚手架变量。

**如何应用：**
1. 写完教程，逐行扫一遍，每个 `# ↓ 你的代码 ↓` 下面必须是空行或仅有注释
2. 不能有任何可执行的 Python 代码
3. **练习描述不能给答案：** `# ■ 练习 X.X` 下面的描述只说明"做什么(what)"，不写"怎么做(how)"。比如可以说"从 statistics 导入 mean 和 median"但不能写 `from statistics import mean, median`。教学部分的细讲放在练习区之上、在 `print(\n + ===)` 之上
4. 可以保留脚手架的变量定义（如 `returns = [...]`）
5. **综合练习区更严格：** 不能有任何可执行的演示代码。配套函数统一放进 `dayXX_utils.py`，由用户自己 import。综合练习只有一个 `# ↓ 你的代码 ↓`，上面只写题目描述
6. **反向检查清单：** 扫完每个 `# ↓ 你的代码 ↓` 确认下面没代码后，再扫一遍确认每个练习描述没有泄漏答案

**关联：** [[claude-code-mistakes-log]]（第3条"知识诅咒"）
**Why:** 用户练习是学习核心环节，我预填答案等于替用户做作业，完全违背了"练习先行"原则。
**How to apply:** 写完教程后做一次"反向检查"——确认每个练习区都是空的。
