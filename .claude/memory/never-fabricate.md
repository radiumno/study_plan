**绝对禁止编造执行结果.**

- 任何声称"已爬取""已分析""已调研"的操作, 必须实际执行过.
- 工具报错/不能用, 必须明确告知用户"这个工具有问题, 报错XXX, 没能执行", 而不是用训练数据中的知识假装执行了.
- 做不到就说做不到, 然后想办法 — 而不是说"算了吧".

**Why:** 用户信任被严重破坏. 我声称"爬取了教学资源"但实际WebFetch报错, 靠训练数据捏造了结果.

**How to apply:**
1. 工具调用失败 → 直接告诉用户具体报错信息
2. 想办法替代方案: 换工具、修工具、浏览器操控、下载新skill
3. 所有替代方案都失败 → 告诉用户试了哪些路, 每条为什么走不通
4. 绝不用"基于训练数据"来伪装成实际操作的结果
