## 第1周：Python起步（5/26 - 6/1）· 1h/天
> 岗位对应：编程是量化开发的基础能力。招聘面试第一关就是手写代码，现在开始建立编程思维。
> 配套视频：[林粒粒呀《3小时超快速入门Python》](https://b23.tv/BV1Jgf6YvE8e) — 本周跟着看，讲到的概念同步敲代码

**本周目标：** 能写简单的Python脚本，掌握变量/控制流/集合/函数，注册GitHub


### Day 1｜5/26（二）· 环境搭建 + 第一行代码

- **安装** Python 3.12+、VS Code、Python插件（30min）
- **视频** 看林粒粒呀前30min：变量、数据类型、print()（30min）
- **练习：** 写一个 Hello World + 用变量输出自我介绍
- **产出：** 注册 GitHub，建仓库 `study_plan`，把第一个py文件push上去

### Day 2｜5/27（三）· 字符串 + 用户输入

- **视频** 看林粒粒呀30-60min：字符串、f-string、input()（30min）
- **练习** 写一个简单的问答程序：问名字→问年龄→打招呼（30min）
- **产出：** `hello.py` 推送到 GitHub

### Day 3｜5/28（四）· 控制流

- **视频** 看林粒粒呀60-90min：if/elif/else、for/while（30min）
- **练习：** 猜数字游戏（程序随机一个数，用户猜，提示大了小了）（30min）
- **产出：** `guess_number.py`

### Day 4｜5/29（五）· 列表 + 字典

- **视频** 看林粒粒呀90-120min：list、dict操作（30min）
- **练习：** 学生成绩管理器 — 用dict存学生姓名和分数，支持增删改查（30min）
- **产出：** `grade_manager.py`

### Day 5｜5/30（六）· 函数

- **视频** 看林粒粒呀120-150min：def、参数、返回值（30min）
- **练习：** 把前几天的脚本重构成函数版（30min）
- **产出：** 重构后的 `guess_number.py` + `grade_manager.py`

### Day 6｜5/31（日）· 小实战：CLI计算器

- 综合运用本周所学，写一个命令行计算器（60min）
- 支持功能：加减乘除、历史记录（存在列表里）、循环运行直到输入 exit
- **产出：** `calculator.py`

### Day 7｜6/1（一）· 总结 + GitHub整理

- 回顾本周所有概念，查漏补缺（20min）
- 完善代码注释，整理 GitHub 仓库（README、文件归档）（20min）
- 看完林粒粒呀剩余部分（20min）
- **产出：** GitHub `study_plan` 仓库有 4-5 个 py 文件 + README
- **下周预告：** 字符串进阶、文件读写、异常处理 → 第一个正经CLI项目
